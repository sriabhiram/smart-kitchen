# SmartLunch AI

An open-source and hosted platform for school lunch providers and small cloud kitchens to manage meal subscriptions, menus, kitchen operations, and parent communication.

## Goals

- Help providers manage recurring meal subscriptions and daily meal counts.
- Give parents a simple way to manage meal preferences and subscriptions.
- Use AI to assist with common questions and operational tasks, with business rules enforced by the backend.
- Support both self-hosted deployments and a managed SaaS offering.

## Initial technology stack

- Frontend: React, TypeScript, Vite
- Backend: Python, FastAPI
- Database: PostgreSQL
- AI: OpenAI API, introduced after core workflows are working

## Project status

Early development. The initial focus is a secure, multi-tenant backend and validation with school lunch providers.
